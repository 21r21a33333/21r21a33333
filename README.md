## About

I'm Diwakar — a **Blockchain & Systems Engineer** who works close to the metal. I write production **Rust** for Bitcoin, EVM, and cross-chain systems where correctness and security aren't optional.

My comfort zone is the hard part: **protocol engineering, secure signing & custody, custom TEE-compatible servers, high-throughput indexing, and routing / arbitrage engines** — designed with clean hexagonal boundaries and tested against real invariants.

- 🦀 Rust-first, with Go, C++, TypeScript and Solidity in the toolbox
- ⛓️ Bitcoin Script, HTLCs, multisig, EVM, cross-chain settlement
- 🧩 Distributed systems, event-driven indexers, applied cryptography (FHE, TEE)
- 📍 Hyderabad, India
